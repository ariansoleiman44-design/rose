# 🌹 3D Blooming Rose

A beautiful 3D rose visualization that slowly blooms like a real flower, featuring romantic lighting and glowing effects.

## ✨ Features

- **Realistic 3D Rose Model** - High-quality GLTF model with detailed petals, stem, and leaves
- **Blooming Animation** - Watch the rose slowly open over 6 seconds
- **Romantic Effects** - Pulsating glow, bokeh particles, and gradient background
- **Interactive Controls** - Drag to rotate, scroll to zoom
- **Optimized Performance** - Smooth 60fps animation with Three.js

## 🚀 View Online

Visit: **https://ariansoleiman44-design.github.io/rose/**

## 💻 Run Locally

1. Clone this repository
2. Start a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open http://localhost:8000 in your browser

## 🛠️ Built With

- [Three.js](https://threejs.org/) - 3D Graphics Library
- WebGL - Hardware-accelerated 3D rendering
- GLTF - 3D model format
